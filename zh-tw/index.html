金竑精密股份有限公司｜KINWA 金和車床：高速精密車床與 CNC 車床

1968 年從一台車床開始的台灣車床製造商
#

金竑精密股份有限公司（CHIN HUNG MACHINERY CO., LTD.）以 KINWA Lathe／金和車床為主要品牌，專注於手動車床與 CNC 車床的研發、製造及全球銷售。1968 年，創辦人張哲夫先生在台中市忠孝路以一台車床從事加工起家；1973 年成立金和機器廠並投入車床製造；1980 年遷至台中市大雅區，改組為金竑精密股份有限公司。

超過半世紀以來，金和車床持續在台灣設計與製造車床，產品涵蓋高速精密車床、重切削精密車床、大型重切削車床，以及櫛式、斜床式與平台式 CNC 車床。官方資料指出，KINWA 車床銷日已超過 600 台，銷美已超過 4,000 台。

機台產品介紹
#

金和車床的產品分為手動車床與 CNC 車床兩大類：

手動車床
#

  • CH 系列高速精密車床 — CH-400、CH-430、CH-530，床面上旋徑 406–532 mm，主軸孔徑 51–78 mm，5 HP 主軸馬達。適合一般加工、維修、模具、教育訓練與多樣少量生產。
  • CHD 系列重切削精密車床 — CHD-560、CHD-660、CHD-760，床面上旋徑 560–760 mm，主軸孔徑 86–104 mm，10 HP 主軸馬達，適合較大工件與重切削。
  • CHK 系列大型重切削車床 — CHK-860、CHK-1020，床面上旋徑 Ø860–Ø1020 mm，主軸孔徑 105／153 mm，兩心間最長可達 8,500 mm，適合大型與長軸工件。

CNC 車床
#

  • CL 系列 - 櫛式 — CL-10、CL-100，體積精巧、換刀行程短，適合小型零件、棒材與多角形加工。
  • CL 系列 - 斜床式 — CL-220、CL-250、CL-280、CL-320，8–15 吋夾頭，棒材容量最高 115 mm，可選配動力刀塔。
  • CL 系列 - 平台式 — CL-650、CL-38、CL-58、CL-68、CL-78，床面上旋徑最高 1,500 mm，主軸孔徑最高 530 mm，適合大型與長軸工件。

應用產業
#

KINWA 車床可應用於油氣輸送管、汽車與機車零件、工業零件、醫療設備及自動化機械。官方公司介紹也列出一般機械加工、模具與治具、能源與傳動零件、長軸與大型工件、維修與單件加工、教育訓練等應用。

  • 油氣輸送管 — 法蘭、閥體、管件、接頭與長軸。
  • 汽車與機車零件 — 軸類、輪轂、襯套、煞車零件、轉向與傳動零件。
  • 零件與工業零組件 — 軸、套筒、齒輪胚、緊固件、液壓與氣壓零件。
  • 醫療設備 — 醫療器材與設備用的精密車削零件。
  • 自動化機械 — 機械設備、自動化產線、機械手整合與客製 OEM 零件。

為什麼選擇 KINWA 金和車床
#

  • 超過半世紀的車床製造經驗 — 從結構設計、零組件選用、加工、組裝到精度檢驗，以長期穩定運轉為核心。
  • 台灣製造 — 車床在台灣生產，具備完整加工與組裝能力。
  • 多種床身結構 — 手動車床、櫛式、斜床式與平台式 CNC 車床，涵蓋不同工件尺寸、產能與刀具配置。
  • 國際市場與 OEM 經驗 — 1980 年起與 Kingston Machine Tool Mfg., Inc. 以 KINGSTON 品牌合作拓展美國市場；1985 年起透過日商 G-NET 以 HAMAMATSUKOKI 品牌 OEM 銷日。
  • 依加工條件選機 — 依工件材質、直徑、長度、重量、精度、切削量與產能需求評估機型。
  • 長期支援 — 透過 KINWA 與海外經銷商提供產品支援、零件與售後服務。
